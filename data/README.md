# Carseats dataset

`carseats.csv` is the Carseats dataset that accompanies *An Introduction to
Statistical Learning* by Gareth James, Daniela Witten, Trevor Hastie and
Robert Tibshirani.

- 400 rows, one per store.
- Columns: `Sales` plus 10 predictors (`CompPrice`, `Income`, `Advertising`,
  `Population`, `Price`, `ShelveLoc`, `Age`, `Education`, `Urban`, `US`).
- The leading `rownames` column of the source file is dropped when the data is
  loaded.

Source: the ISLR `Carseats` table, retrieved from the RDatasets mirror
(<https://vincentarelbundock.github.io/Rdatasets/csv/ISLR/Carseats.csv>). It is
redistributed here for reproducibility; refer to the ISLR book for terms of use.
